Welcome to Flappy Bird Game

A simple, colorful, and responsive Flappy Bird-style web game built using HTML, CSS, and JavaScript. The game features smooth animations, moving pipes, scoring, collision detection, a best-score system, pause/resume controls, and a responsive design for desktop and mobile devices.

🎮 Live Gameplay

The player controls a bird and must fly through the gaps between moving pipes without hitting them.

Goal: Get the highest score possible and beat your best score! 🏆

✨ Features:

🐦 Flappy Bird-style gameplay
🎮 Click/tap to flap
⌨️ Spacebar and Arrow Up controls
🚧 Moving pipes
💥 Collision detection
🏆 Score tracking
⭐ Best score saved using localStorage
📈 Increasing difficulty as the score increases
⏸️ Pause and resume functionality
🔄 Restart game option
🏠 Main menu
📱 Responsive design
☁️ Animated clouds
☀️ Animated sun
🌄 Background hills
🌱 Animated ground
🎨 Colorful modern UI.

🛠️ Technologies Used
HTML5
CSS3
JavaScript
DOM Manipulation
CSS Animations
Local Storage API
✨ Smooth animations
📱 Mobile and desktop support
🖱️ Mouse and touch controls
